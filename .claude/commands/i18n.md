# i18n（翻訳ファイルの更新）

このコマンドは翻訳ファイル（POT/PO/MO）を最新の状態に更新します。

## 前提

wp-env が起動していない場合は先に `npm run start` で起動してください。

## 手順

### 1. POTファイルの生成

```bash
composer i18n:pot
```

`src/` 配下と `tscf.php` など全PHPファイルから翻訳対象文字列を抽出し、
`languages/tscf.pot` を生成・更新します。

### 2. POファイルの更新

```bash
composer i18n:update
```

`languages/tscf.pot` の内容をもとに `languages/tscf-ja.po` を更新します。
新しい文字列が追加され、削除された文字列には `#~` の `obsolete` フラグが付きます。

### 3. MOファイルのコンパイル

```bash
composer i18n:mo
```

`languages/tscf-ja.po` をコンパイルして `languages/tscf-ja.mo` を生成します。

### 4. JS 翻訳 JSON の生成

```bash
composer i18n:json
```

PO ファイルをもとに、WordPress が JS で翻訳を読み込むための JSON ファイルを生成します。
`assets/js/src/` 配下の JS で `@wordpress/i18n` の翻訳関数（`__()`等）を使っている文字列がある場合に JSON ファイルが生成されます。翻訳関数を使っていない場合は `Created 0 files` となります。

### まとめて実行

```bash
composer i18n
```

上記4ステップを一括実行します。

### PHPに翻訳文字列を追加したとき（ステップ1・2）

```bash
composer i18n:po
```

`i18n:pot`（POT生成）+ `i18n:update`（PO更新）をまとめて実行します。
PHP ファイルに `__()` などで新しい翻訳文字列を追加した後に使います。

### POを編集した後にコンパイルのみ実行（ステップ3・4）

```bash
composer i18n:compile
```

`languages/tscf-ja.po` を直接編集した場合など、POT の再生成なしに MO と JSON だけ更新したいときに使います（`i18n:mo` + `i18n:json` の組み合わせ）。

## 翻訳の追加・編集

`languages/tscf-ja.po` を直接編集するか、[Poedit](https://poedit.net/) などのツールを使って翻訳を追加してください。

編集後は必ず `composer i18n:compile` を実行して MO・JSON ファイルを更新してください。

## スキャン除外ディレクトリ

`i18n:pot` では以下のディレクトリをスキャン対象から除外しています（`composer.json` の `--exclude` 参照）。

| ディレクトリ | 除外理由 |
|---|---|
| `tests` | テストコードは翻訳対象外 |
| `node_modules` | npm パッケージ（サードパーティ）。自分のコードではないため除外 |
| `vendor` | Composer パッケージ（サードパーティ）。同上 |
| `assets/lib` | Ace エディタなど bundled されたサードパーティライブラリ。ファイルサイズが大きく（最大 1.6MB）、翻訳文字列も含まない |
| `assets/js/dist` | JS のコンパイル済み出力物。翻訳文字列は `assets/js/src` のソースコードに存在するため、dist をスキャンすると重複・変形して抽出される恐れがある |

`assets/js/src` はスキャン対象に含めています。将来 `@wordpress/i18n` を使う JS 翻訳を追加した場合、自動的に POT に反映されます。

## コミット対象ファイル

- `languages/tscf.pot` - 翻訳テンプレート（コミットする）
- `languages/tscf-ja.po` - 日本語翻訳（コミットする）
- `languages/tscf-ja.mo` - コンパイル済みバイナリ（コミットする）
- `languages/tscf-ja-{hash}.json` - JS 翻訳 JSON（JS 翻訳を追加したらコミットする）
